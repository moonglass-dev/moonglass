# Auto-rollback report delivery

the agent sends unreported events after the first heartbeat exchange and each new one, at most 16 unacknowledged, and marks them on `AUTO_ROLLBACK_ACK`; the server stores each report before acknowledging it and closes on a report for another server's app or an unknown ack (`docs/specs/connection.md`, "Auto-rollback reports")
