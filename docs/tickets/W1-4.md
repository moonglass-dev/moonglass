# Add the agent connection and heartbeat over outbound WSS

After enrolment the agent dials the control plane on an outbound `wss://` connection with mutual TLS 1.3 using the W1-3 Ed25519 identities, sends `Heartbeat` messages every 30 seconds by default, and reconnects with exponential backoff and full jitter. The behaviour is `docs/specs/connection.md`; the dependency is ADR-0012.

Out of scope: Deploy, SwitchRelease, Rollback, RunPreDeploy (W2-2), install scripts (W1-6), live logs (W4-4), moving enrolment onto TLS.
