# Complete the AGENTS.md repo map

list `deploy`, `update` and `releasetest` under `internal/<package>/` (R-6 finding 7)

The repo map in `AGENTS.md` names the product packages under `internal/<package>/`, but it leaves out three that already exist: `internal/deploy`, `internal/update` and `internal/releasetest`. After this ticket the map's `internal/<package>/` row lists every directory under `internal/`. Agents use the map to find code, so it has to match the tree.

## Scope

- `AGENTS.md`: in the "Repo map" table, rewrite the `internal/<package>/` row only.
  - Add `deploy` and `update` to the alphabetical list of product packages, so it reads `agent`, `api`, `cli`, `deploy`, `keys`, `policy`, `protocol`, `proxy`, `registry`, `release`, `server`, `store`, `update`.
  - Add `releasetest` next to the existing `installtest` note, in the same style: `releasetest` (tests for `.github/workflows/release.yml`). This wording comes from the package comment in `internal/releasetest/release_test.go`.
- No other row, section or file changes.

## Acceptance criteria

- The `internal/<package>/` row names every directory under `internal/` (`ls internal/`), and no others: `agent`, `api`, `cli`, `deploy`, `installtest`, `keys`, `policy`, `protocol`, `proxy`, `registry`, `release`, `releasetest`, `server`, `store`, `update`.
- `installtest` and `releasetest` are each described as tests for what they cover (`scripts/install` and `.github/workflows/release.yml`), not as product code.
- `git diff main -- AGENTS.md` changes only that one table row. All other lines stay the same, including the trusted-core list, which this finding does not cover.
- The old working name does not appear. Docs are exempt from the banned-word list, and none of those words are added anyway.
- `make ci` is green and `scripts/verify check FR6-7` passes every gate.
