# Drop the svelte.config.js banned-words exemption

Delete `ui/svelte.config.js` from `bannedWordsSkip` and change its row in `parse_test.go` to not exempt (R-4 finding 4).

ADR-0016 decision 3 (amended 2026-11-19) says `ui/svelte.config.js` does not exist: SvelteKit 3.2 takes the adapter from `sveltekit(...)` in `ui/vite.config.ts`, which keeps its exemption. The `ui/svelte.config.js` exemption is dead code left over from before that amendment, and `AGENTS.md` says to delete the old path when a design changes. After this ticket, added lines in a `ui/svelte.config.js` go through the banned-words gate like any other source file.

## Scope

- `tools/pipeline/verify.go`: in `bannedWordsSkip`, delete the `f == "ui/svelte.config.js" ||` clause. Leave the `.md`, `docs/`, `go.mod`, `go.sum`, `ui/vite.config.ts` and `ui/scaffold_test.go` clauses unchanged. The doc comment above it already names only `ui/vite.config.ts` and `ui/scaffold_test.go`, so it stays as it is.
- `tools/pipeline/parse_test.go`: in `TestBannedWordsSkip`, change the `"ui/svelte.config.js"` row from `true` to `false`. Leave every other row unchanged, including `"docs/tickets/T-1/svelte.config.js": true` (exempt because it is under `docs/`).

## Acceptance criteria

- `./tools/pipeline TestBannedWordsSkip` passes with `bannedWordsSkip("ui/svelte.config.js")` returning `false`, and every other row keeps its current expected value.
- `grep -n 'svelte.config.js' tools/pipeline/verify.go` prints nothing.
- No other file changes. `testdata/tests.txt` is unchanged, because no test is added or renamed.
- `make ci` is green and `scripts/verify check FR4-4` passes every gate.

## Out of scope

- FR4-1, FR4-2, FR4-3 and FR4-5, the other R-4 fixes.
- Any change to the `ui/vite.config.ts` or `ui/scaffold_test.go` exemptions, or to ADR-0016.

## Security notes

None of the threat-model boundaries (`docs/threat-model.md` §3) or the trusted core (§7) are touched. The change narrows a pipeline gate and widens nothing: one fewer file skips the banned-words check that `AGENTS.md` requires of added lines outside docs.
