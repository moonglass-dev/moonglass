# Bootstrap the repository

## Outcome

`make ci` is green on a clean clone. Static linux/amd64 and linux/arm64 builds. `AGENTS.md`, `CLAUDE.md` and the test-list snapshot exist. The prompt it ran from is in the git history at `docs/prompts/01-bootstrap-repo.md`.

## Out of scope

Product code beyond `moonglass version`, `.proto` files, UI, Docker configuration, anything for a later ticket. No Go module dependencies.

## Acceptance tests

- `TestVersionPrintsVersionCommitAndDate`: `moonglass version` prints version, commit and build date, defaulting to `dev`, `unknown`, `unknown`.
- `TestUsageOnMissingOrUnknownCommand`: no arguments, or an unknown subcommand, prints usage to stderr and exits with status 2.

## Security notes

None. CI pins every action to a full commit SHA and runs with `contents: read`.

## Done when

- `make ci` is green and both tests pass.
- `file bin/moonglass-linux-amd64 bin/moonglass-linux-arm64` reports statically linked executables.
- No `TODO`, `FIXME`, `XXX` or `HACK` in Go code, the `Makefile` or CI files.
