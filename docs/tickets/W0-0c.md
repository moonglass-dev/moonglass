# Exclude generated protobuf from the size gate

## Outcome

The verify `size` gate does not count generated `*.pb.go` files toward the 800-line non-test cap. A ticket that checks in generated protobuf (as W0-3 / ADR-0008 require) can still pass verify if the rest of the non-test diff is under the cap. Oversized hand-written diffs still fail. `docs/harness.md` matches the gate, and `scripts/test-ticket` covers both cases.

## Out of scope

Changing the cap itself. Excluding other generated or vendored files. Product code. Protocol changes.

The harness ticket-id pattern is `W0-1` / `W12-3`, so this ticket is implemented by hand. Do not invent a second id to force it through `scripts/ticket`.

## Acceptance tests

`make test-harness` covers:

- An 850-line hand-written non-test file still fails the size gate.
- The same volume of generated `*.pb.go`, plus a small in-package change, passes verify.

`make ci` stays green.
