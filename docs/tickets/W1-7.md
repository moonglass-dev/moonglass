# Add a CI memory-budget check for agent and proxy

## Outcome

CI fails when the combined idle RSS of `moonglass agent` and `moonglass proxy` is above the 100 MB hard ceiling in stack §6 (the G1 gate: "Agent and proxy together ≤ 100 MB"). Measurement uses the existing `scripts/measure-memory` (RSS in KiB on Linux via `/proc` and on macOS via `ps`). The behaviour is `docs/specs/memory.md`, which this ticket writes and may edit.

The hard ceiling is 102400 KiB (100 MiB). The 77 MB figure in the stack is a target, not the fail line. SPIKE-1 is still deferred; do not invent a different public number, and do not change ADR-0001.

The check starts a real `moonglass proxy` (data dir, as in W1-5) and a real `moonglass agent connect` to a local TLS control plane (as in W1-4), samples each process with `scripts/measure-memory --pid`, and fails if the sum is above the ceiling. Ports and data directories are temp / `:0`, so two worktrees can run the check at once. No container images, fleet or Postgres.

`make memory-budget` runs the check and is a step of `make ci`, so GitHub CI and local `make ci` both run it.

## Out of scope

Install scripts and systemd units (W1-6). Changing the 100 MB ceiling or dropping HTTP/3. 48-hour growth, p99 under load, or proxy-upgrade measurements (SPIKE-1). Deploy path, Docker, fleet wipe. Do not amend ADR-0001.

## Acceptance tests

- `TestProxyAndAgentIdleUnderBudget` (`./internal/proxy`): starts the proxy and the agent (connected to a local test control plane), measures RSS of both processes with `scripts/measure-memory`, and fails if the sum is greater than 102400 KiB. It needs no Docker and no non-loopback network.

`make ci` is red when the check fails.

## Security notes

none. The check starts local test processes only; it does not read cloud tokens or print enrolment bearer values.

## Done when

- `make ci` is green and the named test passes, including on GitHub Actions (`ubuntu-latest`).
- `docs/specs/memory.md` matches the implementation.
- `cgo` stays disabled; `make build-all` remains a static ELF.
