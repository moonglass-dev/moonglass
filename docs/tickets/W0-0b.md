# Add Claude Code project settings

## Outcome

The ticket harness can run unattended. `.claude/settings.json` exists, is deny-by-default (`permissions.defaultMode` is `dontAsk`), and allows only `make` (enumerated official targets), `go test`/`build`/`vet`, `git add`/`commit`/`status`/`diff`/`log`, and file read/edit tools inside the repository. `scripts/ticket run W0-1 --dry-run` no longer reports a missing settings file.

## Out of scope

Changes to `scripts/ticket`, schemas, or CI. Product code. Relaxing a deny rule to make an interactive session more convenient. The Makefile may only be changed to quote and validate `PKG`/`NAME` so recipes cannot inject a shell.

The harness ticket-id pattern is `W0-1` / `W12-3`, so this ticket is implemented by hand and reviewed as Core. Do not invent a second id to force it through `scripts/ticket`.

## Acceptance tests

None. This ticket adds a guard file, not Go behaviour. After it merges, `scripts/ticket run W0-1 --dry-run` must not list `.claude/settings.json` as missing, and `make ci` stays green.

## Security notes

This file is the main unattended-agent guard (see `docs/harness.md`). Deny rules must keep covering:

- `git push` (including `git -C` / `git -c` wrappers), `git reset`, `git rebase`, `--force`, `--no-verify`, `--amend`
- `rm -rf` / `rm -fr`, `sudo`, `curl`, `wget`, `ssh`, and other network or package installs (`go get`/`install`, `brew`, `npm`, `pip`, …)
- Reading `.env*`, `secrets`, `~/.ssh`, `~/.aws`, `~/Library`, and paths outside the working tree
- Editing protected paths: `.github`, `.claude`, `Makefile`, `.golangci.yml`, `AGENTS.md`, `CLAUDE.md`, `docs/adr`, `*.proto`, `*.pb.go`, `scripts/ticket`, `schemas`, `.gitattributes`, `.gitmodules`, `go.work*`, and `.git`
- `make -f` / `--file` / `SHELL=`, and `go test -exec` / `-toolexec`

`permissions.disableBypassPermissionsMode` and `permissions.disableAutoMode` are `disable`. Writes and reads outside the working directories are blocked. Agents must not be able to edit this file after it merges.

## Done when

- `.claude/settings.json` is committed and valid JSON.
- `.claude/settings.local.json` is gitignored, so a local allow cannot be committed by mistake.
- `make ci` is green.
- Dry-running the next ticket no longer reports a missing settings file.
