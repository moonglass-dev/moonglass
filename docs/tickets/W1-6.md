# Add the install script and hardened systemd units

## Outcome

`scripts/install` installs the `moonglass` static binary and the units under `deploy/systemd/`. Every artifact is verified with `ssh-keygen -Y verify` against two pinned release keys before anything is written (ADR-0007 decision 1). The service user is unprivileged; only the agent unit has the Docker group; the proxy binds :80 and :443 with `CAP_NET_BIND_SERVICE` only. Behaviour: `docs/specs/install.md`.

The production public keys are not in the tree. The script holds two marked `OWNER-PASTE` lines for the owner to fill in.

## Out of scope

The in-process verifier, channels, staged rollout and revert (W7-6). Signing real artifacts. Installing Docker.

## Done when

- `make ci` is green without a FIDO2 token, Docker or a network.
- The spec matches the script, and the missing-key hole is obvious.
