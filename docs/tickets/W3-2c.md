# `keys init` registration and recovery pins

`keys init` checks `MOONGLASS_URL` and `MOONGLASS_TOKEN` before it writes the file, calls `keys.recovery.add` once the file is flushed, keeps the file and prints the retry when registration fails, and records the recipient in `pins.json`; the pins file itself with the D22 recovery check and print rules (`docs/specs/secrets.md`, "The pins file")
