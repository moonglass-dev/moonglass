# Memory budget with the W2-4c agent

`TestProxyAndAgentIdleUnderBudget` starts the agent with `--proxy-socket <temp admin socket> --tls-issuer internal`, skips when no Docker Engine opens except under `CI` (where it fails), and `docs/specs/memory.md` says it needs a Docker Engine and that the agent pushes to the test's proxy (R-4 finding 1).

Since W2-4c, `moonglass agent connect` opens the Docker Engine before it connects and runs `deploy.Proxy.Run` against `--proxy-socket`, which defaults to the system socket `/run/moonglass-proxy/admin.sock` (`docs/specs/connection.md`, "Commands"). After this ticket the G1 gate measures an agent that pushes to the proxy the test started, it follows the Docker rule in `docs/specs/deploy-suite.md`, and it never touches a proxy outside its temp directory.

## Scope

- `internal/proxy/memory_test.go`:
  - Before it builds the binary, the test checks for a Docker Engine with the package's existing `testEngine(t)` helper (`internal/proxy/agent_push_test.go`). That helper skips when no Engine answers and fails when `CI` is set.
  - The agent process gets `--proxy-socket <adminSock> --tls-issuer internal` as well as its current flags. `<adminSock>` is the temp socket passed to the proxy's `--admin-socket`.
  - After the admin socket appears and the agent has connected, the test polls `GET /config/apps/http/grace_period` over the admin socket until it decodes to `"30s"`, which is the agent's first push (`docs/specs/release.md`, "Proxy config"). It fails within `startTimeout` and names the socket and the last value it got. The 3-second idle and the sample come after that.
- `docs/specs/memory.md`:
  - Step 3 shows the agent command with `--proxy-socket <temp admin socket> --tls-issuer internal`.
  - Step 4 also waits for the agent's first push to the test's proxy.
  - The paragraph after the steps says the test needs a Docker Engine, because `agent connect` opens one (`docs/specs/connection.md`). With no Engine it skips, except under `CI`, where it fails (`docs/specs/deploy-suite.md`). It also says the agent pushes only to the test's own proxy. Drop "no Docker". Keep the lines about no Postgres, no non-loopback network, no cloud token and the enrolment token.

## Acceptance criteria

- With a Docker Engine, `make memory-budget` passes. The log line shows proxy and agent RSS, and the total is at or under 102400 KiB.
- With no Engine and `CI` unset, `TestProxyAndAgentIdleUnderBudget` skips before it builds the binary or starts a process. The skip message names the Engine error.
- With no Engine and `CI` set, the test fails with the `testEngine` message saying that CI must provide Docker.
- The agent's argument list in the test contains `--proxy-socket` followed by the same path the proxy got as `--admin-socket`, and `--tls-issuer internal`. No path under `/run` appears in the test.
- The test samples memory only after the admin socket returns `"30s"` for `/config/apps/http/grace_period`.
- `docs/specs/memory.md` no longer says that the test needs no Docker. It says that the test needs a Docker Engine, states the skip and CI rule, and says that the agent pushes to the test's proxy.
- The ceiling (102400 KiB), the idle settle (3 s) and the failure message are unchanged.
- No new helper duplicates `testEngine` or `adminClient`. The test reuses them.

## Security notes

- Two worktrees can run this test at once (`AGENTS.md` "Testing rules"). The agent pushes only to the temp admin socket. It never posts a config to a system proxy at `/run/moonglass-proxy/admin.sock`, which would drop that host's live routes (R-4 finding 1).
- `--tls-issuer internal` keeps the pushed config free of ACME, so the test makes no request to a public CA and needs no non-loopback network.
- The test deploys nothing and creates no Docker resources. It only pings the Engine. The enrolment token is still never printed or logged.
- `docs/threat-model.md`: no trust boundary changes. The proxy admin socket's access rule (ADR-0001 decision 3, `docs/specs/proxy.md`) is not touched, because the test socket sits in the test's temp directory.
