# Image-in-use by error type only

`removeImage` in internal/deploy recognises an image in use by the client's typed conflict error through `errdefs.IsConflict(err)` from `github.com/containerd/errdefs` (ADR-0017), which becomes a direct module in go.mod, and `isConflict`'s text match is deleted (R-6 finding 2)
